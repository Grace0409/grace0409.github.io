서버가 사용자를 대신해 요청을 보내 주는 기능이 있으면 생길 수 있는 취약점입니다.

## 어떤 공격인가

이미지 URL을 받아 서버가 대신 다운로드해 주는 기능 같은 걸 떠올리면 됩니다. 이 요청 대상을 내부 주소로 바꾸면, 외부에서는 닿을 수 없는 내부 서비스나 파일에 서버를 통해 접근할 수 있습니다.

```text
url=http://127.0.0.1/flag.txt
url=http://localhost/flag.txt
```

## 블랙리스트는 쉽게 뚫린다

`localhost`나 `127.0.0.1` 문자열만 막는 필터는 약합니다. 같은 주소를 다른 표기법으로 적으면 문자열은 다른데 실제로는 같은 곳을 가리킵니다.

| 표기 | 의미 |
| --- | --- |
| `http://2130706433/` | 127.0.0.1의 10진수 |
| `http://0x7f000001/` | 16진수 |
| `http://0177.0.0.1/` | 8진수 |
| `http://127.1/` | 축약 표기 |

포트를 모를 때는 Burp Intruder로 포트 범위를 브루트포싱하고, 응답 길이가 다른(실제 응답이 온) 포트를 찾습니다.

## 막는 법

블랙리스트 대신 허용 목록(allowlist)으로 접근 가능한 대상만 명시합니다. 입력 URL을 정규화한 뒤 실제 접속할 IP를 해석해서, 사설 대역이나 루프백으로 가는 요청을 차단합니다.

실제 적용은 [web-ssrf 라이트업](/posts/web-ssrf/)에 있습니다.

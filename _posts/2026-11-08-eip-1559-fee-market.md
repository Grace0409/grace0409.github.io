이더리움에서 거래를 보내려면 가스비(수수료)를 내야 합니다. 예전에는 이 가스비를 사용자가 직접 정했습니다. 지갑에서 느림, 보통, 빠름 중 하나를 고르고, 거래가 안 들어가면 더 높은 가격으로 다시 보냈습니다.

2021년 8월 5일 London 하드포크(네트워크 규칙을 바꾸는 업데이트)에서 EIP-1559가 적용되면서 이 방식이 바뀌었습니다. 가스비를 기본요금과 팁으로 나누고, 기본요금은 네트워크가 자동으로 정합니다 :)

## 예전 방식: 경매

예전 가스비는 입찰이었습니다. 사용자가 가스 가격을 적어 내면 채굴자(블록을 만드는 쪽)가 높은 가격부터 골라 블록에 넣었습니다. 포함된 거래는 자기가 적은 가격을 그대로 냈습니다. EIP 문서는 이 방식의 문제를 네 가지로 듭니다.

1. 가격이 크게 출렁입니다. 거래 하나를 더 넣는 비용은 가스 가격이 1이든 10이든 네트워크에는 거의 같습니다. 그런데 가격은 열 배까지 벌어졌습니다.
2. 오래 기다립니다. 블록 크기가 고정이라서 수요가 잠깐 몰리면 여러 블록을 기다렸습니다.
3. 과하게 냅니다. 얼마를 적어야 들어갈지 알 수 없어서 다들 넉넉하게 적습니다.
4. 장기적으로 불안정합니다. 블록 보상이 줄고 수수료만 남는 체인은 흔들릴 수 있다는 우려가 있었습니다.

## 바뀐 규칙: 기본요금과 팁

가스비는 두 가지 값으로 나뉩니다. 가스는 거래가 쓰는 계산량의 단위이고, 가스비는 가스량에 가스 가격을 곱한 값입니다. 가스 가격의 단위는 gwei이며 1 gwei는 10억분의 1 ETH입니다.

base fee는 네트워크가 블록마다 자동으로 정하는 가스 가격입니다. 이 돈은 누구에게도 가지 않고 소각(영구히 없앰)됩니다. priority fee는 블록을 만드는 쪽에 주는 팁입니다. 사용자는 여기에 max fee, 곧 가스 1개당 최대로 낼 가격을 정합니다.

실제로 내는 가격은 base fee에 팁을 더한 값이고 max fee를 넘지 않습니다. max fee가 남으면 그만큼은 청구되지 않습니다.

예를 들어 보겠습니다. 제가 가정한 숫자이고 실제 거래 기록은 아닙니다. max fee 50 gwei, 팁 2 gwei로 보냈는데 그 블록의 base fee가 30 gwei이면 가스 1개당 32 gwei를 냅니다. 21,000 가스가 드는 단순 송금이라면 총 672,000 gwei(0.000672 ETH)가 나갑니다. 이 중 630,000 gwei는 소각되고 42,000 gwei는 팁으로 갑니다.

## base fee 계산

base fee는 직전 블록이 얼마나 찼는지로 정해집니다. 블록에는 쓸 수 있는 가스의 한도가 있고, 목표치는 그 한도의 절반입니다. 직전 블록이 목표치보다 많이 찼으면 base fee가 오르고, 덜 찼으면 내립니다. 한 블록에서 변하는 폭은 최대 12.5%입니다.

블록은 목표치의 두 배까지 찰 수 있습니다. 수요가 잠깐 몰려도 블록이 커져서 처리하고, 몰림이 이어지면 가격이 올라 수요가 줄어듭니다. 문서의 계산을 코드로 옮기면 이렇습니다.

```js
// 다음 블록의 base fee (오를 때는 최소 1 wei)
function nextBaseFee(parentBase, parentGasLimit, parentGasUsed) {
  const target = parentGasLimit / 2n;
  if (parentGasUsed === target) return parentBase;
  if (parentGasUsed > target) {
    const delta = (parentBase * (parentGasUsed - target)) / target / 8n;
    return parentBase + (delta > 1n ? delta : 1n);
  }
  const delta = (parentBase * (target - parentGasUsed)) / target / 8n;
  return parentBase - delta;
}
```

## 알아 둘 점

평균 가스비가 내려가는 것은 아닙니다. 수요가 길게 몰리면 base fee가 블록마다 12.5%씩 복리로 오릅니다. 대신 다음 블록의 base fee 범위가 직전 블록만으로 정해져서 예측하기 쉽고, 지갑이 가격을 알아서 잡아 줄 수 있습니다.

팁도 남아 있습니다. 급하면 팁을 올려야 하고, max fee를 너무 낮게 잡으면 base fee가 오를 때 거래가 대기 상태로 남습니다.

컨트랙트(블록체인에 올라간 프로그램)는 `block.basefee`로 현재 base fee를 읽습니다. 이 기능은 London에서 EIP-3198로 함께 들어갔습니다. blob(대용량 데이터)에 붙는 수수료(EIP-4844)도 별도의 base fee를 두고 같은 원리로 조정됩니다.

## 확인한 내용

### London 첫 블록

London의 첫 블록은 12,965,000번입니다. 바로 앞 블록과 이후 몇 개를 공개 RPC(블록체인 노드에 데이터를 요청하는 공개 주소)로 조회했습니다.

| 블록 | gasLimit | base fee |
|---|---|---|
| 12,964,999 (포크 직전) | 15,029,237 | 없음 |
| 12,965,000 | 30,029,122 | 1 gwei |
| 12,965,001 | 29,999,798 | 1.124967822 gwei |
| 12,965,002 | 29,970,503 | 1.265451421 gwei |

포크 직전 블록에는 base fee가 없습니다. 포크 블록에서 gasLimit이 두 배가 되면서 base fee가 1 gwei로 시작합니다. 이후 블록이 거의 가득 차서 base fee가 12.5%에 가깝게 올랐습니다. 위 코드에 값을 넣으면 1124967822 wei와 1265451421 wei가 나오고, 관측값과 정확히 같았습니다.

### 조회 당시의 블록

조회 당시의 최신 블록은 base fee가 약 0.181 gwei, gasLimit이 60,000,000이었습니다. 최근 10개 블록의 거래 3,207건 중 88.8%가 EIP-1559 타입(0x2)이었습니다. 예전 방식인 레거시 타입(0x0)도 9.3% 남아 있었습니다. 같은 때 노드가 추천한 팁은 약 0.0000137 gwei로, base fee의 1만분의 1도 안 됐습니다.

### 소각량

구간은 블록 26,421,009번부터 26,422,009번까지 1,001개 블록(3시간 남짓)입니다. 블록마다 base fee에 사용한 가스를 곱해 더했습니다. 소각량은 약 6.27 ETH였습니다. London 이후 누적은 ultrasound.money의 공개 API가 약 4,643,873 ETH를 돌려줬습니다. 이 값은 외부 집계라서 제가 검증하지는 못했습니다.

## 확인하지 못한 것

London 이후 누적 소각량은 직접 합산하지 못했습니다. 약 1,400만 개의 블록을 읽어야 합니다. 이번에 쓴 무료 RPC는 오래된 블록을 제공하지 않거나 한 번에 조회할 수 있는 범위를 1만 블록으로 제한했습니다. 위의 6.27 ETH도 blob 수수료의 소각은 뺀 base fee 소각분입니다.

AVF(Adaptive Verification Framework)는 이후 SVF, ZT-SVF로 이어지는 연구의 출발점입니다.

## 연구 배경

- **분산 학습 환경의 취약성** — 연합학습(FL)에서는 중앙 서버가 노드 내부 동작을 직접 검증하기 어려워 데이터 오염, 은닉 공격, 모델 조작에 취약합니다.
- **단일 테스트의 한계** — 기존 검증은 하나의 절대 테스트에 의존해서, 공격자가 검증 패턴을 학습하면 우회할 수 있습니다.
- **시간축 반영 부족** — 단일 시점 기준 판단으로는 지속적인 저강도 공격이나 Non-IID 환경을 잡기 어렵습니다.

## 제안 모델

세 가지 관점의 테스트로 노드를 평가하고, 시간에 따라 위험도를 누적합니다.

1. **다중 절대 테스트** — Golden Batch(직접 오차), Known-outcome(구조적 관계), Consistency(시간 안정성)
2. **원시 위험도** — `raw_i = αE_g + βE_k + γE_c` (α = β = γ = 1/3)
3. **누적 위험도(지수 평활)** — `R_i(t) = λ·raw_i(t) + (1 − λ)·R_i(t − 1)` (λ = 0.6)
4. **상태 분류** — Trusted / Uncertain / Suspicious
5. **적응형 검증 강도** — 위험도가 낮은 노드는 최소 검증, 높은 노드는 집중 검증 (검증 복잡도 O(N) 유지)

## 실험 결과

| 실험 | 결과 |
| --- | --- |
| 다중 테스트 구조 효과 | AVF F1 약 92~94% vs Golden Batch 단독 66~70% → **약 18~22%p 향상** |
| 검증 비용 vs 탐지 성능 | Static-high 대비 **검증 비용 68.6% 절감**, F1 8.1%p 향상 |
| 시간축 누적 구조 효과 | **F1 94.5%, AUROC 97.8%, FPR 1.5%, Recall 93.2%** (즉시 위험도 방식 F1 74%) |

## 정리 & 다음 연구

다중 테스트 통합으로 단일 구조 대비 F1을 최대 35%p 올렸고, 위험도 기반 검증으로 비용도 크게 줄였습니다. 다만 검증률을 경험적으로 정했다는 한계가 남아서, 이를 게임이론으로 바꾼 것이 [SVF](/posts/svf-wisa2026/)입니다. FLTrust, FoolsGold, Krum 같은 강건 집계 기법과의 비교도 앞으로 해 볼 예정입니다.

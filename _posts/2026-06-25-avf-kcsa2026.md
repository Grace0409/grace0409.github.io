AVF(Adaptive Verification Framework)는 SVF, ZT-SVF로 이어진 연구의 시작점입니다.

## 왜 시작했나

연합학습에서는 중앙 서버가 노드 안에서 무슨 일이 일어나는지 직접 볼 수 없습니다. 그래서 데이터 오염이나 모델 조작에 약합니다.

기존 검증은 테스트 하나에 기대는 경우가 많았습니다. 공격자가 그 패턴을 배우면 그냥 피해 갑니다. 한 시점만 보고 판단하니까, 약하게 오래 들어오는 공격이나 Non-IID 환경도 잘 잡지 못했습니다.

## 제안한 방법

노드를 세 가지 테스트로 봅니다. Golden Batch는 직접 오차를, Known-outcome은 구조적 관계를, Consistency는 시간에 따른 안정성을 봅니다. 세 값을 같은 비중으로 더해서 원시 위험도를 만듭니다.

```text
raw_i  = αE_g + βE_k + γE_c          (α = β = γ = 1/3)
R_i(t) = λ·raw_i(t) + (1 - λ)·R_i(t-1)   (λ = 0.6)
```

이 값을 지수 평활로 계속 쌓아 갑니다. 쌓인 위험도로 노드를 Trusted, Uncertain, Suspicious 셋으로 나누고 검증 강도를 다르게 줍니다. 위험도가 낮으면 가볍게, 높으면 집중해서 봅니다. 그래도 검증 복잡도는 O(N)으로 유지됩니다.

## 실험 결과

| 실험 | 결과 |
| --- | --- |
| 다중 테스트 구조 | AVF F1 약 92~94%, Golden Batch 단독은 66~70%. 약 18~22%p 높음 |
| 검증 비용과 탐지 성능 | Static-high보다 검증 비용 68.6% 적고 F1은 8.1%p 높음 |
| 시간축 누적 구조 | F1 94.5%, AUROC 97.8%, FPR 1.5%, Recall 93.2%. 즉시 위험도 방식은 F1 74% |

## 남은 숙제

테스트를 합친 것만으로 F1이 단일 구조보다 최대 35%p 올랐습니다. 비용도 꽤 줄었습니다! 그런데 검증률을 경험적으로 정했다는 한계가 남았습니다. 이걸 게임이론으로 바꾼 게 [SVF](/posts/svf-wisa2026/)입니다. FLTrust, FoolsGold, Krum 같은 강건 집계 기법과도 비교해 볼 계획입니다.

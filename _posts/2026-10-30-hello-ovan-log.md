보안 공부 기록을 남기려고 블로그를 열었습니다!

공부한 건 머릿속에만 두면 금방 흐려집니다. 이제부터는 여기에 꾸준히 남겨 보려고 합니다.

## 왜 블로그인가

풀었던 문제, 헤맸던 곳, 결국 어떻게 풀었는지. 나중에 다시 꺼내 보려면 적어 둬야 합니다.

남에게 설명하듯 써 보면 내가 정말 이해했는지도 바로 드러납니다. 그리고 시간이 좀 지나서 돌아보면, 어디서 출발해서 어디까지 왔는지 보일 것 같습니다.

## 카테고리

| 카테고리 | 이런 글을 씁니다 |
| --- | --- |
| 개발 | 직접 만든 것, 만들면서 배운 것 |
| CTF/Wargame | 대회 후기, 문제 풀이 |
| Bug Bounty | 취약점 분석과 제보 과정 |
| 블로그/기술문서 | 개념 정리, 공부 노트, 블로그 소식 |
| 논문/컨퍼런스 | 논문 리뷰, 학회 참관기 |
| 공모전/자격증 | 도전기, 준비 기록 |

## 앞으로

완벽한 글보다 꾸준한 기록이 목표입니다. 작은 거라도 배운 게 있으면 짧게라도 남기겠습니다.

잘 부탁드립니다 :)
